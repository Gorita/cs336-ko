# 과제별 한국어 가이드

각 과제별로 한국어 학습 가이드를 작성합니다. 과제 코드 자체는 Stanford 공식 repo에서 받습니다.

## 과제 목록

| 과제 | 내용 | 공식 Repo |
|------|------|----------|
| Assignment 1: Basics | BPE, Transformer, Optimizer 구현 | [stanford-cs336/assignment1-basics](https://github.com/stanford-cs336/assignment1-basics) |
| Assignment 2: Systems | Attention 최적화, 분산 학습 | [stanford-cs336/assignment2-systems](https://github.com/stanford-cs336/assignment2-systems) |
| Assignment 3: Scaling | Scaling laws 측정/fitting | [stanford-cs336/assignment3-scaling](https://github.com/stanford-cs336/assignment3-scaling) |
| Assignment 4: Data | 데이터 필터링/중복 제거 | [stanford-cs336/assignment4-data](https://github.com/stanford-cs336/assignment4-data) |
| Assignment 5: Alignment | SFT + RL for reasoning | [stanford-cs336/assignment5-alignment](https://github.com/stanford-cs336/assignment5-alignment) |

## 작업 방법

`./setup.sh` 실행 후, 각 과제는 `workspace/assignment{1-5}-*/` 에서 작업합니다.
한국어 가이드는 이 디렉토리(`assignments/`) 의 각 폴더를 참고하세요.

## ⚠️ 솔루션 공개 정책

본 repo는 **과제 솔루션을 공개하지 않습니다**. 학습 가이드, 개념 정리, 막힌 부분 회고만 공유합니다.
다른 학생들의 학습 윤리를 존중하기 위함입니다.
